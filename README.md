# imgtool-c
imgtool is a fast, dependency-free CLI application written entirely in C for processing BMP files. It supports reading image headers, extracting metadata, and applying various transformations including grayscale, negative inversion, blur, brightness adjustment, cropping, and rotation.
A C-based command-line tool for BMP image manipulation.
Features:

    Read and display BMP header metadata

    Apply visual filters: Grayscale, Invert, Blur, Brightness

    Spatial transformations: Crop, Rotate (90°, 180°)

    Safely write modified raw pixel data to new .bmp files

run ./imgtool -info for specific info how to run it
